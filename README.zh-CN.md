# 世界杯 2026 观赛手册 ⚽

一个手机优先的世界杯 2026 预测小应用 —— 湾区 / 美国境内场次视角。给小组排名次、推演淘汰赛对阵图，还能看来自真实预测市场的实时胜率。

**▶ 开始玩：**
- 🇨🇳 中文 —— https://ericthlai.github.io/worldcup26-bracket/zh/
- 🇬🇧 English —— https://ericthlai.github.io/worldcup26-bracket/

> 打开就能用，所有选择自动存在你自己的浏览器里。无需登录，不上传任何信息。纯属娱乐。

## 功能
- **赛程** —— 美国境内全部 52 场小组赛，每场带一条来自 [Polymarket](https://polymarket.com) 预测市场的实时**胜 / 平 / 胜**概率条
- **小组** —— 点击球队排名次；前 2 名晋级，第 3 名进入「最佳第 3」候选池
- **对阵** —— 可交互的淘汰赛对阵图，从小组排名自动带入，外加实时**夺冠概率榜**
- **分享** —— 一键生成可分享的预测卡片图

## 技术
单页静态网页，无需构建：[Preact](https://preactjs.com) + [HTM](https://github.com/developit/htm) 本地引入，预测存在 `localStorage`，实时胜率由浏览器直接调用 Polymarket 公开的 Gamma API。托管在 GitHub Pages（免费）。

英文版（`/`）和中文版（`/zh/`）是同一个应用的两份独立维护的代码副本，并非共用代码；两者共用同一份球队数据文件和同一个 localStorage 存储键，所以你的预测会在两种语言间同步。页脚链接可互相切换。

## 本地运行

python -m http.server 8000

## 已知局限
- 英文版和中文版是同一个应用的两份独立维护的代码副本，不是同一套代码；改了一边的 bug，另一边不会自动跟着改。
- 赛程页只列出美国境内的 52 场小组赛，加拿大和墨西哥主办的比赛不在赛程页显示；不过小组积分榜和自动填充的对阵图会通过实时比分把全部 72 场小组赛都算进去。
- 8 个「最佳第三名」名额只有在全部 12 个小组都踢满 6 场后才会自动填入，哪怕某支球队已经提前锁定名额也是如此。
- 第三名与淘汰赛签位的对应关系是本项目自行推算的结果，不是 FIFA 官方表格的逐条照搬；小组赛收官日之前的自动填充仅供参考。
- 实时比分来自 ESPN 的公开 scoreboard API，夺冠概率来自 Polymarket 的公开 API。ESPN 请求把默认结果上限提高到 200，确保可以返回全部 104 场比赛；但任一方仍可能随时更改响应格式、球队名拼写或缩写规则。
- 运行 `node --test test/*.test.mjs` 可检查中英文页面的请求配置与场馆、存储损坏恢复、对阵预测的依赖清理和即时保存；这些测试不覆盖赛事同分判定规则和实时数据源的响应格式。
- 预测结果只存在你浏览器的 `localStorage` 里；清除网站数据、换浏览器或换设备、使用隐私/无痕模式都会丢失记录，没有账号也没有云同步。
- 球员阵容数据（预测首发、身价）是赛前根据公开资料（Transfermarkt、官方大名单）整理的预测值，不会随实际比赛日的阵容变化实时更新。
